# Bug Reports

## 🇬🇧 English

This folder contains bug reports created during my QA practice.

Each report follows a consistent structure and includes:

- Summary
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority (when applicable)
- Additional Notes

The purpose of these reports is to improve my ability to identify, describe, and communicate software defects.

---

## 🇷🇺 Русский

В этой папке находятся баг-репорты, созданные во время моей практики по тестированию.

Каждый отчёт оформлен по единому шаблону и содержит:

- Краткое описание
- Шаги воспроизведения
- Ожидаемый результат
- Фактический результат
- Severity
- Priority (при необходимости)
- Дополнительные комментарии

Цель этих работ — развивать навык поиска, анализа и грамотного описания программных ошибок.
