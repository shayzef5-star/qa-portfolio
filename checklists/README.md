# Checklists

## 🇬🇧 English

This folder contains testing checklists used during exploratory and functional testing.

Checklists help ensure that important scenarios are not missed during the testing process.

---

## 🇷🇺 Русский

В этой папке находятся чек-листы, используемые во время исследовательского и функционального тестирования.

Чек-листы помогают последовательно проверять функциональность и не пропускать важные сценарии.
