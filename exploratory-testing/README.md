# Exploratory Testing

## 🇬🇧 English

This folder contains reports from exploratory testing sessions.

The goal of exploratory testing is to investigate application behavior, discover unexpected issues, and improve testing skills through practical analysis.

---

## 🇷🇺 Русский

В этой папке находятся результаты исследовательского тестирования различных веб-приложений.

Цель исследовательского тестирования — изучать поведение приложения, находить неожиданные проблемы и развивать практические навыки тестирования.
